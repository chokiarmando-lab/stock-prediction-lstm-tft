# Stock Price Prediction using LSTM and TFT
This project focuses on predicting stock prices of LQ45 companies using deep learning models, specifically Long Short-Term Memory (LSTM) and Temporal Fusion Transformer (TFT). The dataset is collected from Yahoo Finance and stored in MySQL for structured data management before being processed for time series forecasting.

## Dataset
- Source: Yahoo Finance
- Stocks: BBCA, TLKM, ASII, UNVR, ICBP
- Period: 2020–2025
- Features: Open, High, Low, Close, Volume

## Pipeline
1. Data Collection (Yahoo Finance)
2. Data Storage (MySQL)
3. Exploratory Data Analysis (EDA)
4. Data Preprocessing
5. LSTM Model
6. TFT Model
7. Model Evaluation
